# Product overview

## Problem

Language learners can encounter vocabulary, idioms, and grammar in subtitles without enough context or explanation to understand and remember them.

## Intended users

People learning a language who want to use subtitle material as contextual study material. The first target audience and supported learning levels still need validation.

## High-level idea

A user provides subtitles, chooses a target language and proficiency level (for example, German B1), and receives contextual explanations that help them learn from the material.

## Tentative MVP scope

The tentative MVP is a focused subtitle-based learning experience covering contextual vocabulary, idioms, and grammar. Input formats, workflow details, and the exact MVP boundary remain open.

## Initial MVP non-goals

- Audiobook processing
- Mobile applications
- Payments
- Multi-user collaboration

## Assumptions and decisions to validate

- **Assumption:** Learners want explanations tied to subtitle context.
- **Assumption:** A language and proficiency-level selection is useful to tailor explanations.
- **Open:** Which subtitle formats, languages, and learning levels should be supported first?
- **Open:** How should users provide subtitles, and what should the first complete learning workflow include?
- **Open:** Which explanation types and output format best serve learners?
